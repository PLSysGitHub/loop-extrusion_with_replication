This directory contains source code for running simulations.

The file bacterial_species.py contains a container class for storing relevant parameters for a bacterial simulation, such as the replication speed, cell size, growth rate, etc. If you want to simulate your own system, you can use this as a template, and simply change the type of bacterium that's created in the main simulation files.

simulations_1D contains code for simulating a set of loop extrusion trajectories (during replication).

simulations_3D contains code for polymer simulations, where loop-extruder positions can be loaded in from a file.
